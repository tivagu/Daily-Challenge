# Portable Motion Inference Runner — project kit

**Python 3.10+ / 90 minutes / dataset-inference submission profile.** Self-authored practice, not an official competition task. No PyTorch installation, Docker or hardware needed today.

Read [problem.md](problem.md), send your proposed workflow in chat, then implement `src/infer.py`. The model and sensor-window features are provided; you implement the forward computation, CLI and ordered CSV output.

## Files

- Supplied data: [data README](../../data/2026-11-06/README.md), features, model, format-only sample submission and five public fixture sets.
- Supplied tools: `check_public_tests.py`, `package_submission.py`, `requirements.txt`, `challenge.json` and [SUBMISSION.md](SUBMISSION.md).
- You write: `src/infer.py`, tests of your own and `REPORT.md`.
- Generated by you: `outputs/submission.csv` and a ZIP in `submission/`.

## Run

From `E:/TU_HOC/ROADMAP_STORAGE/DAILY_CHALLENGES/ISSUED/2026-11-06`:

```text
python check_public_tests.py
python src/infer.py --features ../../data/2026-11-06/features.csv --model ../../data/2026-11-06/model.json --output outputs/submission.csv
python package_submission.py
```

The starter intentionally raises `NotImplementedError`, so it will fail all fixtures before implementation. The checker runs each test in a fresh working directory and passes absolute input/model/output paths: use the paths you receive, not assumptions about the current directory.

Optional venv, created by you with Windows Python:

```text
python -m venv .venv
.venv\Scripts\python.exe check_public_tests.py
```

Use your interpreter's real path if its venv has `bin/` instead of `Scripts/`. No packages need installing. Keep source outside `.venv`. See [SUBMISSION.md](SUBMISSION.md) for reproducibility and ZIP layout; commit source, configs and your report to your GitHub repository when ready, without venv/cache/ZIP. No repository or environment is created automatically.

This task does not assume completion of the previous C++ challenge. Its results will help choose later AI tasks, including PyTorch when the task requires it.
